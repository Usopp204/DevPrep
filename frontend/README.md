# Frontend (React + Vite + TS)

## Purpose
Client UI for real-time mock interviews and reports.

## Local Run (No Docker)
1. Ensure `.env` exists at repo root (copy from `.env.example`).
2. Install deps:
   ```
   npm install
   ```
3. Run:
   ```
   npm run dev
   ```
4. Health check:
   ```
   http://localhost:5173
   ```
